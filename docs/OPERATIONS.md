# 部署与验收清单

上海如静知华信息科技有限公司 · https://www.zhuatech.cn/

1. 取得正式商业授权；确认本项目业务流程符合本企业制度。
2. 使用专用 MySQL 8.4 数据库和全新强密码，`DEMO_MODE=false`；不要直接复用公开演示配置。
3. 配置 HTTPS 入口、可信反向代理、网络防火墙和最小权限账号；默认 Compose 仅绑定到 127.0.0.1。
4. 运行 `sh scripts/test.sh` 和 `docker compose config`；通过健康接口、登录、核心业务完整流程和失败分支验收。
5. 规划 MySQL 与附件表的加密备份、恢复演练、容量、监控告警、日志保留与审计留存。示例 Compose 不含托管监控或远程灾备。
6. 对外部资金、身份、服务台、通知或会计系统的对接，需在授权实施中完成联调与双向对账。不要将内部登记状态误当外部系统执行证明。

本项目提供可运行的业务核心与自动化验收，不代表已经对某企业的特定合规要求、并发峰值或生产环境完成认证。
